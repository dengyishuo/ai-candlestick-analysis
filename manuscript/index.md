# 前言 
蜡烛图是一种高度压缩的价格语言：一根图形同时保存开盘、最高、最低和收盘，连续图形又构成市场推进、停顿与拒绝的视觉语法。它适合提出问题，却不能仅凭名称证明未来方向。

本书以史蒂夫·尼森整理的经典形态谱系为参照 [@nison2001]，使用 `xquant-work/My-Pkg` 中eQuant的R与Python双生态，把图形经验改写为可计算、可复现、可证伪的研究。所有行情图来自 `eFinCharts`，形态使用 `eCandleSticks`，指标使用 `eTTR`，完整策略接口使用 `ebacktest`。正文只读取冻结数据，不在渲染时联网。

全书采用“结构为主、方向为辅”的组织原则。基础篇（第[蜡烛图：从图形语言到可检验证据](intro.html)—[R与Python绘制可审计的蜡烛图](candle.html)章）建立图形语言和可审计流程；形态篇（第[单根K线：压力、拒绝与失衡](single-candle.html)—[形态字典与统一扫描](pattern-dictionary.html)章）依次研究单根、双根、三根及多根结构，并在章内区分看涨、看跌和中性候选；证据篇（第[形态汇聚、冲突与概率评分](pattern-scoring.html)—[蜡烛图与成交量价格剖面](profile.html)章）研究汇聚、趋势、位置、动量、成交量和市场状态；决策篇（第[蜡烛图与期权决策](option.html)—[从形态到可运行研究：综合案例](comprehensive.html)章）讨论风险暴露、套期保值和完整样本外研究。附录提供环境、API字典、市场状态扩展和发布检查表。

这样的顺序刻意避免把形态名称写成确定预测。同一几何只有结合此前趋势、所处位置、波动与成交量后，才获得条件性的方向含义；看涨或看跌是需要数据检验的候选假设，而不是目录标签所保证的结论。

每章固定采用“问题现场—学习目标—经典形态与市场机制—可计算定义—研究设计—R实现—Python实现—图形诊断—证据与稳健性—AI协作实验室—失效条件与常见误区—本章小结与练习”的结构。经典解释、研究假设、样本结果和稳健结论严格分开。

早期的排版版本使用 **knitr** [@xie2015] 与 **bookdown** 生成；当前在线版已改为纯 Markdown + pandoc 构建，与 R 工具链解耦。以下记录研究复现所需的核心包版本：

- **knitr**：`1.51`
- **bookdown**：`0.47`
- **eCandleSticks**：`0.1.1`
